ay 3 - ATM Simulator

A simple console-based ATM Simulator built in Java as part of my 30 Days Challenge.

Features

Check account balance

Deposit money

Withdraw money

Validate deposit and withdrawal amounts

Prevent withdrawal when the balance is insufficient

Exit the ATM safely

Technologies Used

Java

Scanner for user input

switch statement

Methods

while loop

Basic conditional statements

printf for formatted output

How to Run

Make sure Java JDK is installed.

Open the terminal in this project folder.

Compile the program:

javac ATMSimulator.java

Run the program:

java -cp . ATMSimulator

ATM Menu

Welcome to the ATM Simulator!
1. Check Balance
2. Deposit
3. Withdraw
4. Exit

Example

Please select an option: 2
Enter amount to deposit: 1000
$1000.00 deposited successfully.

Please select an option: 1
Your current balance is: $1000.00
