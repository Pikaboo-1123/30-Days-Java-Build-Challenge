# 🏦 Day 5 - Banking System

A simple console-based Banking System built using Java.

## 📌 Features

- Create a bank account
- Deposit money
- Withdraw money
- Check account balance
- Display account details
- Exit the application

## 🛠️ Concepts Used

- Java Classes and Objects
- Constructors
- Encapsulation basics
- Methods
- Scanner for user input
- if-else statements
- switch statement
- while loop
- Basic input validation

How to Run

Compile the program:

javac BankAccount.java BankingSystem.java

Run the program:

java -cp . BankingSystem
