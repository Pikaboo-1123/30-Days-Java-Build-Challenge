# 🎓 Day 2 – Student Grade Calculator

This is **Day 2** of my **30 Days Java Mini Project Challenge**.

The **Student Grade Calculator** is a simple Java console-based application that calculates a student's total marks, percentage, and grade based on the marks entered for different subjects.

## 📌 Project Overview

The program takes marks as input from the user, calculates the total marks and percentage, and then assigns a grade according to the percentage obtained.

This project was created to practice basic Java programming concepts and improve problem-solving skills.

## ✨ Features

* Enter marks for multiple subjects
* Calculate total marks
* Calculate percentage
* Determine the student's grade
* Display the final result
* Simple and beginner-friendly console interface

## 🛠️ Technologies Used

* **Java**
* **Scanner Class**
* Java Conditional Statements
* Basic Arithmetic Operators

## 📚 Concepts Practiced

* Variables and Data Types
* User Input using `Scanner`
* Arithmetic Operations
* `if-else` Conditions
* Conditional Logic
* Type Casting
* Basic Java Program Structure

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project folder

Navigate to:

```text
Day 2 Student Grade Calculator
```

### 3. Compile the program

```bash
javac GradeCalculator.java
```

### 4. Run the program

```bash
java GradeCalculator
```
